# Пепельное королевство — Telegram RPG

Файлы проекта: `index.html`, `style.css`, `graphics.js`, `audio.js`, `game.js`.

- Canvas-портрет героя и противников без внешних изображений.
- Интерактивная Node Map, туман войны по уровню, маршруты с анимированными пунктирными линиями.
- Городские активности: продавец с фильтром уровня, скупщик с продажей всего хлама, таверна.
- Пошаговый бой с встряской, вспышками, плавающими числами урона, зельями и отступлением.
- 25% шанс события при путешествии: засада, телега с добычей или странник.
- Адаптивная мобильная верстка, Telegram WebApp expand/haptics, звук Web Audio, сохранение в localStorage.

## Запуск
Открой `index.html` в современном браузере или размести все файлы на HTTPS-хостинге (например, GitHub Pages) и используй URL в Telegram Mini App. Telegram API необязателен для локальной проверки. Сохранение привязано к браузеру и устройству; для синхронизации между устройствами нужен сервер.
